# Preguntero LED · 2º parcial

Práctica de las preguntas de **Lógica y Estructuras Discretas (LED, UTN FRC)** para el 2º parcial: Unidad 5 (relaciones y funciones), Unidad 6 (grafos y árboles) y Unidad 7 (estructuras algebraicas y álgebra de Boole).

- 143 preguntas sacadas de 21 parciales y cuestionarios de Moodle (2021 a 2026), copiadas tal cual, cada una con la cantidad de veces que apareció.
- Las preguntas de arrastrar o completar tienen un espacio por cada bloque, como en Moodle; las de opción múltiple se puntúan como Moodle (las incorrectas restan).
- Filtros combinables: Unidad 5, 6 y 7, "Las que más se repiten", "Tu parcial P02" y "Sin cuestionarios de práctica".
- Machetes por unidad, repaso de errores y progreso guardado en el navegador.

Cada respuesta indica su origen: **oficial** (96, confirmada con la corrección de Moodle), **según el apunte** (40, resuelta con el material de la cátedra) o **dudosa** (7, conviene confirmarla con el profe).

Para usarla, abrí `index.html` en el navegador o entrá por GitHub Pages. El banco completo está en `datos/preguntas.json`.
